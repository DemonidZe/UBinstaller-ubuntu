# UBinstaller-ubuntu
Ubilling Ubuntu installation script
For Ubuntu 14.04, 16.04, 18.04, 20.04, 24.04, 26.04

1. Ubuntu-server LTS installed without any services other than OpenSSH
2. apt-get update
3. apt-get upgrade
4. For Ubuntu 24.04 / 26.04: go to `24.04_26.04_LTS` and run `./UBinstaller_ubuntu.sh`

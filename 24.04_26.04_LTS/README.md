# UBinstaller-ubuntu (24.04 & 26.04 LTS)
Ubilling installation script for Ubuntu 24.04 LTS and 26.04 LTS

1. Clean Ubuntu Server 24.04 LTS or 26.04 LTS installed (only OpenSSH)
2. Download `UBinstaller-ubuntu/24.04_26.04_LTS/*`  `wget -qO- https://github.com/DemonidZe/UBinstaller-ubuntu/archive/refs/heads/master.tar.gz | tar -xz --strip-components=1 UBinstaller-ubuntu-master/24.04_26.04_LTS`
3. `chmod a+x UBinstaller_ubuntu.sh`
4. `./UBinstaller_ubuntu.sh`
